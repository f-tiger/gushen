# 股神（Gushen）—— AI 智能投顾（美股）· 架构设计文档

> 版本：v0.2
> 定位：**AI 智能投顾**——依据用户目标与风险画像，自动构建/再平衡美股投资组合、追求稳健长期回报，最终指导真实投资；**模拟盘作为组合算法的验证器**。
> 配套调研：`docs/research.md`（数据/技术/合规硬约束）、`docs/research-robo-advisor.md`（算法/产品/差异化）。本文档已据两份调研更新。

---

## 1. 产品定位

核心闭环：**画像 → 建组合 → 模拟验证 → 再平衡 → 指导真实投资**。

| 层 | 说明 | 价值 |
|----|------|------|
| **智能投顾层（核心）** | LLM 结构化访谈做风险画像 → 确定性算法构建组合 → 规则化再平衡 | 给用户一个可落地、可解释的组合并持续维护 |
| **模拟验证层** | 在真实/历史行情上回测与模拟盘运行组合 | **选择/校准算法、让用户建立信任**（非附属功能） |
| **AI 表达层** | 投研问答、组合解读、投资者教育 | 把数值结果讲成人话 |

### 1.1 差异化下注（来自调研）

1. **风险画像做深**：现有 robo-advisor 问卷简单、偏保守、无统一规范（研究中仅约 60% 题目有效）→ 用 **LLM 驱动的结构化访谈**替代死板问卷，是 LLM 真正创造价值的环节。
2. **AI 策略 × 透明模拟验证**：让用户先在模拟盘看到「这套 AI 组合过去怎么走」，建立信任再指导真实投资——模拟盘即价值锚点。

### 1.2 合规姿态（已定默认，详见 compliance-stance.md）

**「针对特定用户组合的个性化建议」在美国基本等同受《投资顾问法》监管**，而智能投顾正是最个性化的形态。

**默认已采用 `education_only`（仅教育/非个性化）**：代码层由 `settings.compliance_mode` + `app/services/compliance/guard.py` 强制执行——所有对外投资文本附免责声明、软化个性化指令性措辞。升级到 `advisory`（真个性化投顾）须先完成 `docs/compliance-stance.md` 的清单（含注册 RIA、咨询律师）。

## 2. 技术栈选型

| 层 | 选型 | 理由 |
|----|------|------|
| 后端 API | **Python + FastAPI** | 异步高性能，贴合数据/AI/量化生态 |
| **组合优化** | **PyPortfolioOpt（起步）→ Riskfolio-Lib / skfolio（进阶）** | 覆盖均值方差/BL/风险平价/HRP/最大分散化，活跃维护，直接选型 |
| 数据处理 | pandas / numpy | 行情清洗、指标计算 |
| 回测 | **skfolio（sklearn 接口）/ vectorbt** | 组合回测嵌入验证流水线 |
| 主数据库 | **PostgreSQL** | 事务强一致；扩展一库多能 |
| 时序扩展 | **TimescaleDB** | 行情/净值时序 |
| 向量扩展 | **pgvector / pgvectorscale** | 研报/新闻 RAG，起步不必单独上向量库 |
| 缓存 | **Redis** | 实时行情缓存、排行榜、限流、任务队列 |
| 定时任务 | **Celery / APScheduler** | 拉行情、算再平衡信号、跑回测 |
| AI | **Claude API** | 画像访谈、组合解读、投研问答 |
| 前端 | **React + TypeScript + Vite** | 生态成熟 |
| 图表 | **TradingView Lightweight Charts** | 免费、专业 |
| 部署 | **Docker Compose 起步** | 一键起全套依赖 |

> 存储取舍（research.md §2 验证）：起步「单 PostgreSQL + Timescale + pgvector」承载关系型/时序/向量三类需求即可；达到 **<20ms p99 / 十亿级向量 / 高频重嵌入 MVCC 膨胀**任一阈值前无需拆库。

│  │风险画像│ │组合优化│ │再平衡  │ │回测/模拟│ │行情服务│ │AI ││
│  │(LLM访谈)│ │(数值库)│ │(规则)  │ │ 引擎   │ │        │ │表达││
│  └───┬────┘ └───┬────┘ └───┬────┘ └───┬────┘ └───┬────┘ └─┬─┘│

### 3.1 核心分层铁律（AI 边界，research-robo-advisor.md §4）

| 交给**确定性数值算法** | 交给 **LLM（Claude）** |
|------------------------|------------------------|
| 组合优化、权重计算 | 风险画像**结构化访谈** |
| 再平衡触发与执行 | 组合解读（权重/风险讲人话） |
| 回测统计、风险指标 | 投研问答（RAG） |
| 报价/财务数字（工具调用取回） | 投资者教育 |

**LLM 绝不亲自做数值预测/优化/报价**；所有数字经工具调用从权威数据取回。组合决策保留可复现的输入/参数/结果，为可解释性与合规留痕。

### 3.2 关键数据流

**建组合**：画像结果（目标风险/期限）→ 组合优化服务（选定算法 + 收缩/约束）→ 生成权重 → 落库 → LLM 解读。

**再平衡**：定时任务按触发规则（周期/阈值）检查偏离 → 生成调仓建议 → （模拟盘直接执行 / 真实盘提示用户）。

**模拟验证**：组合 + 历史行情 → 回测引擎 → 收益/回撤/Sharpe → 展示业绩曲线。

## 4. 存储方向

（数据模型细节见下；与 research.md §2 一致。）

- **关系型（PostgreSQL，事务）**：`users`、`risk_profiles`（画像结果）、`portfolios`、`positions`、`orders`、`transactions`、`rebalance_events`、`watchlists`。
- **时序（TimescaleDB）**：`market_bars`（OHLCV）、`portfolio_nav`（组合净值曲线）。
- **向量（pgvector）**：`documents` + `embeddings`（新闻/财报 RAG）。
- **缓存（Redis）**：最新报价、排行榜、限流、任务队列。

要点：资金/持仓/再平衡变更走数据库事务；组合决策与 AI 输出均留可审计记录。

---

## 5. 行情数据源（许可是最大硬约束，research.md §1）

**原型 vs 上线分开算账**：

- **原型/内部验证**：Finnhub 免费档（60 次/分钟、**实时**美股报价 + 新闻 + 财报 + SEC filings）+ yfinance（历史）。
- **对外上线**：免费档普遍**禁止商用/向终端用户展示**（yfinance/Polygon 个人档/Finnhub 免费档均如此）→ **必须切付费商用授权**，预留预算，上线前由法务复核最新 ToS。

**抽象层**：统一 `MarketDataProvider` 接口（`get_bars/get_quote/get_news`），各源做适配器，换源零改业务；缓存 + 多源降级兜底。

---

## 6. AI 方向（重构为智能投顾分层）

1. **风险画像访谈（LLM 主场）**：结构化多轮对话替代死板问卷，产出目标风险/期限，映射到资产配置。差异化核心。
2. **组合解读**：把优化算法给出的权重、风险贡献讲成用户能懂的话，附免责声明。
3. **投研问答（RAG）**：接入行情 + 新闻，数字一律工具调用取回；缓解金融幻觉（research.md §3：现成 LLM 金融任务 ≥10% 幻觉）。
4. **投资者教育**：概念解释、组合逻辑科普。

> 组合的**计算**（优化/权重/再平衡）一律走 §2 的数值库，不交给 LLM。

---

## 7. 组合引擎（本项目技术核心）

- **默认算法**：**风险平价 / HRP**，或 **BL 先验 + 协方差收缩（Ledoit-Wolf/OAS）的均值方差**；**不裸用历史均值方差**（对输入敏感、易出极端权重，research-robo-advisor.md §2）。
- **稳健化手段**：协方差收缩、BL 先验、权重约束/正则化、风险预算。
- **选型不预设最优**：内建统一回测框架，在**自有美股 ETF 池**横评各方法，用业绩曲线选型（research-robo-advisor.md §3：无免费午餐，HRP 未必优于均值方差）。
- **实务约束**（进阶用 Riskfolio-Lib）：换手率、基数、整数股数约束。

## 9. 分阶段路线图（按智能投顾闭环重排）

| 阶段 | 目标 | 交付 |
|------|------|------|
| **P0 地基** | 脚手架、DB、鉴权、Docker Compose | 能起服务、能登录 |
| **P1 行情 + 数据** | Finnhub/yfinance 接入、行情/ETF 池、K线 | 有可用的美股数据底座 |
| **P2 组合引擎** | 集成 PyPortfolioOpt，实现风险平价/HRP/BL，产出权重 | 给定输入能生成组合 |
| **P3 模拟验证** | 回测框架 + 模拟盘，业绩曲线（收益/回撤/Sharpe） | 能验证组合、选算法 |
| **P4 风险画像** | LLM 结构化访谈 → 画像 → 映射配置 | 用户走完访谈得到组合 |
| **P5 AI 表达** | 组合解读 + 投研问答（RAG）+ 教育 | AI 把组合讲清楚 |
| **P6 再平衡** | 触发规则 + 调仓建议（模拟执行/真实提示） | 组合能持续维护 |
| **P7 真实指导** | 依选定合规姿态，落地真实投资指导 | 闭环（须先定合规） |

> 建议顺序理由：**P2+P3 是技术核心**（组合引擎 + 验证），先立住"能生成并验证组合"，画像与 AI 表达是其上的增强，真实指导放最后且依赖合规姿态。

## 10. 风险与注意事项

- **投顾监管（硬约束）**：个性化投资建议受《投资顾问法》监管，智能投顾风险敞口最大；真实指导前必须先定合规姿态并咨询律师（research.md §5）。
- **数据许可（硬约束）**：免费档不覆盖商用展示，上线须付费授权 + 法务复核。
- **算法不预设最优**：一切以自建回测/模拟验证为准，勿套外部论文结论。
- **AI 幻觉**：数字一律工具调用取回，LLM 不碰数值；组合决策留可审计痕迹。
- **可解释性**：LLM 交易系统可解释性不足，受监管场景须留痕（research-robo-advisor.md §4）。
- **成本**：AI 与实时行情是主要开销，用缓存与分级策略控制。
