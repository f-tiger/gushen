## 0. 一句话结论

路线清晰可落地：**组合决策的数值内核交给成熟的确定性优化库，LLM 只做推理/问答/解读/画像访谈**。差异化机会集中在**风险画像做深**和**「AI 策略 + 透明模拟验证」面向散户**这两块。

## 1. 算法内核：直接选型，无需自研

**结论：Python 组合优化生态已成熟，三大库覆盖全部主线方法，可直接选型。**

| 库 | 覆盖方法 | 特点 | 成熟度 |
|----|----------|------|--------|
| **PyPortfolioOpt** | 均值方差/有效前沿、Black-Litterman、HRP、CLA、Mean-Semivariance/Mean-CVaR；内置 Ledoit-Wolf 三目标 + OAS 协方差收缩 | 上手最简单、文档好 | ~5.9k★、MIT、近 100% 测试覆盖、JOSS 2021、v1.6.0(2026-02) |
| **Riskfolio-Lib** | Mean-Risk(含 Kelly)、BL 贝叶斯/增强、风险平价、HRP/HERC、NCO、最坏情况；**26+ 凸风险度量**；支持基数/换手率/整数等**实务约束** | 最全面、贴近实务 | ~4.4k★、基于 CVXPY、Py≥3.10 |
| **skfolio** | Mean-Risk、风险预算、最大分散化、BL 先验、HRP/HERC；**scikit-learn 接口**，支持交叉验证/压力测试 | 与 ML 工作流无缝、便于回测 | BSD-3、arXiv 2507.04176 独立论文佐证 |

**选型建议**：**起步用 PyPortfolioOpt**（快、稳、够用）；需要更丰富风险度量与实务约束（换手率/基数约束）时上 **Riskfolio-Lib**；若组合优化要嵌入 ML/回测流水线，**skfolio** 的 sklearn 接口最顺。三者可并存。

来源：三库官方 README/文档（一手）。

## 2. 均值方差不能裸用 —— 稳健化是核心工程约束

**结论（学界共识）**：经典均值方差(Markowitz)**对输入高度敏感、易产生极端权重**，不能直接用于稳健配置。必须稳健化：

- **协方差收缩**：Ledoit-Wolf / OAS（PyPortfolioOpt 内置）
- **Black-Litterman 先验**：把市场均衡 + 观点融合，缓解期望收益估计误差
- **约束/正则化**：权重上下限、Tikhonov(岭)、lasso、稀疏约束
- **风险预算/风险平价**：可数学上视为「最小方差优化的非线性收缩」，天然稳健、不依赖收益预测

**对本项目**：**默认走风险平价 / HRP 或带 BL 先验 + 收缩的均值方差**，不要裸用历史均值方差。风险平价对散户尤其友好——不需要预测收益、权重稳定、可解释。

来源：arXiv 1902.07449（Amundi, Roncalli 等，一手；Roncalli 为风险平价权威）。

## 3. 没有「最优算法」—— 必须自建回测/模拟验证

**结论**：方法优劣与**市场、时段强相关**，学术对比未能证明某法（如 HRP）在样本内外恒优于均值方差。

> ❌ 被 3 票否决的强断言：「HRP 在样本内外均优于 MVP、Sharpe 更高」——不成立，勿据此预设。

**对本项目**：这**直接印证了"模拟盘验证"的价值**——它不是附属功能，而是**选择/校准组合算法的必要一环**。应内建统一回测框架，在**自己的美股 ETF 池**上横评各方法，用真实业绩曲线说话，而非套用外部论文结论。

来源：arXiv 2305.17523（对比框架成立；强断言被否）。

## 4. LLM 的边界：数值交算法，语言交 LLM

**结论（文献收敛）**：主流架构范式是**把数值/确定性计算交给外部工具，LLM 负责推理与编排**。

**分层架构（本项目采用）**：

| 交给**确定性数值算法** | 交给 **LLM** |
|------------------------|--------------|
| 组合优化、权重计算 | 投研问答（RAG） |
| 再平衡触发与执行 | 组合解读（把权重/风险讲人话） |
| 风险指标、回测统计 | 风险画像**访谈**（结构化对话） |
| 报价/财务数字（工具调用取回） | 投资者教育 |

- 主导模式：多智能体协作、反思机制、工具增强流水线。
- **LLM 绝不亲自做数值预测/优化**——只做语言理解与表达。

**风险边界（须正视）**：现有 LLM 交易系统**可解释性不足、部署鲁棒性存疑**，难直接嵌入受监管场景。→ 组合决策留数值算法的可审计痕迹，LLM 输出仅作解释且留痕。

来源：ACM ICAIF 2025 综述（DOI 10.1145/3768292.3770387）；EMNLP 2025 Findings 综述；drpress 融合架构论文。

## 5. 差异化机会：风险画像 + AI 策略 × 模拟验证

**机会一：把风险画像做深（现有产品的明显短板）**
- 现有 robo-advisor 问卷**比人工顾问提问更少、部分问题与风险无关、无统一规范、结论偏保守**；研究中仅约 **60% 的题目真正影响评估**。
- **我们的打法**：用 **LLM 驱动的结构化访谈**替代死板问卷，把画像做得更深、更贴合，再映射到目标风险/目标日期配置。这是 LLM 能真正创造差异化价值的环节。

**机会二：AI 策略 + 透明模拟验证，面向散户**
- 竞品在把量化工具下沉散户：**eToro 于 2025-08 推出公开 API + AI 助手 Tori**（自动执行、组合优化、七个 Alpha Portfolios），验证了「AI 投顾 + 量化下沉」赛道方向。
- 但其「量化级」多为营销框架、初期仅限部分用户。**留下的空白**：面向普通散户的**深度画像 + 透明可回测的模拟验证 + 可解释组合**。让用户先在模拟盘看到"这套 AI 组合过去怎么走"，建立信任再指导真实投资——正是我们模拟盘定位的价值锚点。

来源：CFA Institute Digest（画像研究，二手，数据 2018/2019）；eToro 官方新闻稿 2025-08 + 多方报道。

## 6. 对本项目的可执行建议

1. **算法内核**：起步 PyPortfolioOpt，**默认风险平价/HRP 或 BL+收缩的均值方差**，不裸用历史均值方差；后续按需引入 Riskfolio-Lib / skfolio。
2. **模拟盘 = 算法验证器**：内建统一回测框架，在自有美股 ETF 池横评各方法，用业绩曲线选型；模拟验证是核心链路不是附属。
3. **AI 分层铁律**：数值/优化/再平衡全交确定性算法并留痕；LLM 只做问答/解读/画像访谈/教育，数字一律工具调用取回。
4. **差异化下注**：把「LLM 结构化风险画像」+「透明可回测的模拟验证」作为主打卖点。
5. **算法可审计**：组合决策保留可复现的输入/参数/结果记录，为可解释性与后续合规留空间。
